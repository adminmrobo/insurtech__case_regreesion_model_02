먼저 우리 데이터의 꼬리Our baseline tail

사례와 비교할 기준: 같은 지표를 우리 데이터에서 먼저 잽니다.

상위 1% 의 금액 비율3.9%
상위 10% 의 금액 비율31.8%
하위 50% 의 금액 비율18.5%
평균 ÷ 중앙값1.41배
흡연자: 사람 → 금액20.5% → 49.5%

꼬리 비율(tail share)은 금액이 큰 사람부터 줄을 세웠을 때 앞쪽 몇 %가 전체 금액의 몇 %를 차지하는지입니다. 모두 같은 금액이면 상위 1%는 1%를 차지합니다(대각선). 위로 볼록할수록 소수에게 몰린 것입니다.

흡연자는 사람의 20.5% 이지만 금액의 49.5% 를 씁니다. 우리 데이터에서 ‘금액을 좌우하는 소수 집단’은 흡연자, 그중에서도 BMI 30 이상인 사람들입니다(1부 1편의 맨 위 띠).

공통 구조

네 사례 모두 금액(또는 기간)이 오른쪽으로 길고, 소수가 전체의 큰 몫을 차지합니다. 그래서 평균 하나로 보고하면 소수의 큰 값이 숨고(1부 1편), 오차가 큰 사람도 소수에 몰립니다(2부 2편).

우리 데이터의 위치

우리 데이터의 꼬리는 가벼운 편입니다: 상위 1% 비율 3.9% 는 자동차보험(38.0%) · 재보험(17.2%) · MEPS(21.7%)보다 훨씬 작습니다. 최댓값이 $63,770 에서 멈추고 0 원도 없기 때문입니다. 대신 ‘흡연’이라는 한 집단이 금액의 절반을 가집니다.

그래서 전략도 다르다

꼬리가 아주 무거운 재보험은 극값 이론(EVT)이 필요하지만, 우리 데이터는 그 전에 소수 집단의 모양(흡연 × 비만)을 모델에 넣는 것이 먼저입니다. 꼬리의 무게를 재고 전략을 고릅니다.

# 배경
- 데이터: 공개 학습용 건강보험 의료비 데이터 1,338행 (https://raw.githubusercontent.com/fintech-data/Revolution/main/data/insurance.csv)
- 열: age(나이) · sex(성별) · bmi(체질량지수) · children(자녀 수) · smoker(흡연 여부) · region(미국 내 지역 4곳) · charges(1년 의료비 청구 금액, 달러 = 맞힐 대상)
- 완전히 같은 행 1건을 빼고 1,337행을 씁니다. 목표값 charges 는 자르거나 고치지 않습니다(고액은 오류가 아니라 꼬리).
- 검증은 charges 10분위로 층화한 StratifiedKFold(n_splits=5, shuffle=True, random_state=42) 입니다. fold별 점수 5개와 평균 ± 표준편차를 냅니다.
- 기준선: 모두에게 학습 데이터 평균만 답하기 (R² = 0 근처)
- 내 수준: [예: 파이썬은 조금, 통계는 처음]

# 반드시 지킬 것
- 기호나 약어(MAE, RMSE, R² 등)는 처음 나올 때 한 줄로 설명하기
- 데이터 증강(합성 행 · 행 복제 · 정답에 잡음 넣기)은 쓰지 않기
- 전처리(표준화 · 인코딩)는 Pipeline 안에서 학습 데이터에만 fit (데이터 누수 금지)
- 여유분 · 하이퍼파라미터는 학습 데이터의 교차검증으로만 고르기 (시험 데이터는 마지막에 한 번만)

비유로 먼저, 뜻은 그다음.

꼬리 비율 (tail share)
앞줄 몇 명이 몫을 얼마나 가져가나. 금액 큰 순서로 상위 p% 가 전체 금액에서 차지하는 비율. 우리 상위 1% = 3.9%.
집중 곡선
볼록할수록 몰려 있다. 가로 = 사람 비율(큰 금액부터), 세로 = 누적 금액 비율. 대각선 = 모두 같은 금액.
심도 (severity)
사고 한 건의 크기. 보험에서 사고 1건당 손해액. 빈도(건수)와 나눠 모델링한다.
감마 GLM
양수 금액용 회귀. 금액이 0 보다 크고 오른쪽으로 긴 분포를 가정한 일반화 선형 모델.
트위디 GLM
0 과 금액을 한 번에. 0 이 많고 나머지는 양수 금액인 순보험료를 한 모델로 맞힌다.
극값 이론 (EVT)
꼬리 끝만 따로 보기. 임계값을 넘는 큰 손해에 일반화 파레토 분포를 맞춘다(McNeil 1997).
분위 회귀
평균 대신 상위 몇 % 를 맞히기. 예: 75% 분위 = 4명 중 3명은 이보다 적게 쓰는 금액. 1부 4편의 비용 비 3 : 1 과 연결.
2단계 모델
쓸까, 얼마나. 0 원이 많은 데이터에서 ‘청구 여부’ 분류와 ‘청구 금액’ 회귀를 나눠 곱한다.

설명용 모형인 것: 이 시리즈는 공개 학습용 건강보험 의료비 데이터(1,338행)를 그대로 씁니다. 가상 데이터를 만들거나 데이터를 증강하지 않습니다. 완전히 같은 행 1건만 빼고, 목표값(charges)은 자르거나 고치지 않습니다. 사례의 숫자는 각 출처의 값이거나 공개 데이터 파일을 직접 계산한 값이며, 사례마다 어느 쪽인지 적었습니다.

주의: 이 시리즈는 교육용 설명입니다. 보험 가입 · 보험료 · 보험금 심사 · 투자 · 의료에 대한 조언이 아닙니다. 데이터는 공개 학습 데이터 원본이며, 실제 보험사의 현재 보험료 산정 · 심사 기준을 뜻하지 않습니다. 건강 정보(흡연 · BMI)는 설명용이며 의료 조언이 아닙니다. 실제 보험료 산정에서 성별 · 지역 · 나이 같은 특성의 사용은 감독 규정에 따라 금지되거나 제한될 수 있습니다.
