문제 1 · 작은 그룹은 범위로Bootstrap interval

흡연자 MAE 를 2,000번 다시 뽑아 잽니다.

부트스트랩은 그룹 안의 사람을 ‘중복을 허락해’ 같은 수만큼 다시 뽑아 MAE 를 재는 일을 2,000번 반복합니다. 2,000개 MAE 의 가운데 95%가 구간입니다. 새 데이터를 만드는 것이 아니라 있는 검증 예측을 다시 세는 것이라 증강이 아닙니다.

문제 4 · 로그 되돌리기 편향과 스미어링Retransformation bias

exp(로그 예측)은 평균을 모자라게 맞힙니다.

log(charges) 를 맞히는 모델은 로그 척도에서 평균을 맞힙니다. 그런데 exp 는 볼록한 함수라서 exp(로그의 평균)은 원래 평균보다 작습니다(옌센 부등식). 그래서 되돌린 예측의 평균은 실제 평균($13,279)보다 낮습니다. 스미어링 보정(Duan, 1983)은 학습 데이터의 로그 잔차 r 로 계수 F = mean(exp(r)) 를 구해 exp(예측)에 곱합니다. F 는 학습 fold 로만 계산합니다.

그래디언트 부스팅: 평균이 맞아짐

평균 예측이 실제보다 -5.0% → +2.4% 로 가까워지고, 과소 추정 비율은 26.2% → 12.0% 로 줄었습니다.

선형 회귀: 오히려 넘침

선형 로그 모델은 -2.4% → +11.1% 로 넘쳤습니다. 스미어링은 ‘잔차의 퍼짐이 모두에게 같다’고 가정하는데, 상호작용이 없는 선형 모델은 흡연자의 잔차가 훨씬 크게 퍼져 이 가정이 깨집니다. 보정 전에 모델부터 고쳐야 합니다(문제 3).

스미어링은 평균(합계)을 맞히는 보정입니다. MAE 는 중앙값에서 가장 작아지므로 보정 후 MAE 는 커집니다(그래디언트 부스팅 $2,135 → $2,692). 지급 준비금처럼 합계가 중요하면 보정하고, 개인 견적의 MAE 가 중요하면 하지 않습니다. 목적을 먼저 정합니다.

용어 사전Glossary

비유로 먼저, 뜻은 그다음.

부트스트랩
주머니에서 다시 뽑기. 같은 크기로 중복을 허락해 다시 뽑아 지표를 여러 번 재고, 가운데 95%를 구간으로.
편향 (평균 잔차)
한쪽으로 쏠린 오차. mean(예측 − 실제). 음수면 체계적으로 적게 잡는다.
비대칭 비용
적게 잡은 1달러가 더 비쌈. 이 편의 가정: 과소 1달러 : 과대 1달러 = 3 : 1.
상호작용 특성
‘둘 다일 때’ 칸. 흡연 × 비만처럼 두 조건이 함께일 때만 1 이 되는 열. 직선 모델이 꺾인 효과를 표현한다.
스미어링
되돌린 값 키우기. exp(로그 예측) × mean(exp(학습 로그 잔차)). 평균을 맞히는 보정(Duan, 1983).
옌센 부등식
곡선은 평균을 휜다. 볼록 함수 f 에서 f(평균) ≤ 평균(f). exp(로그 평균) < 원래 평균.
중첩 교차검증
고르는 시험과 채점 시험을 분리. 안쪽 CV 로 설정을 고르고 바깥 fold 로 채점.
